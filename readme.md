### Installation Guide

Follow these steps to install and apply the theme:

1.  **Download and Extract**
    * Download the theme file (usually a `.zip` or `.tar.gz` archive).
    * Extract the archive. You will now have a folder containing the theme files.

2.  **Move Theme to `.themes` Folder**
    * Open your **Home** directory.
    * If you do not already have a `.themes` folder, create one.
        * *Tip: Folders starting with a dot (`.`) are hidden. Press `Ctrl + H` to show hidden folders in your file manager.*
    * Copy the extracted theme folder (from Step 1) and paste it into the `.themes` directory.

3.  **Enable the Theme**
    * To apply the theme, you must have the **User Themes** GNOME Shell extension installed and enabled.
    * Open the **GNOME Tweaks** tool (you may need to install it).
    * Go to the **Appearance** tab.
    * Click the dropdown menu next to "Shell" and select your newly installed theme.
